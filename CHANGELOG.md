# Changelog

## v0011

- Восстановлена логика v0002 для кнопки **🔢 Проверить номера**: глобальный каталог всех collectible-типов независимо от выбранного канала.
- Каталог формируется через `payments.getStarGifts`, а последний номер каждого типа — через `payments.getUniqueStarGift`.
- Добавлена ограниченная параллельность `CATALOG_CONCURRENCY=6`, чтобы полный список формировался быстро без неограниченного всплеска запросов.
- **🎁 Подарки** снова показывает только экземпляры выбранного канала и не делает проверку последних номеров.
- Точечная проверка по сообщению `DurovsGlasses` сохранена.
- Полная проверка каталога запрещена во время активного сканера или стресс-теста, чтобы не задерживать ловлю.
- Добавлены тесты независимости от канала, сортировки каталога, частичной ошибки и реальной bounded-concurrency логики.
- Версия изменена на v0011.

## v0009

- Исправлено автоматическое определение slug для выбранного обычного подарка по точному базовому `gift_id`.
- Основной lookup выполняется через `payments.getResaleStarGifts(gift_id=...)`; из `StarGiftUnique.slug` удаляется суффикс номера.
- Добавлены fallback-поиски по принадлежащим каналу уникальным подаркам и каталогу обычных подарков.
- Связь `gift_id → slug` сохраняется и повторно используется после перезапуска.
- Заголовок отсутствующего подарка дополняется из каталога Telegram вместо технического текста `Gift <id>`.
- Предварительная проверка канала, выбранного подарка и текущего номера выполняется до выставления состояния `scanner.active`.
- При ошибке preflight задача сканера не создаётся, статус остаётся остановленным, а причина показывается пользователю.
- Добавлены тесты автоматического lookup для `gift_id=5999116401002939514`, извлечения базового slug и безопасного отказа запуска.
- Версия изменена на v0009.

## v0008

- Стресс-тест переведён на один тумблер `ВЫКЛ/ВКЛ`.
- Через пять минут тест автоматически завершается, возвращает тумблер в `ВЫКЛ`, публикует итог и освобождает бот для работы.
- Удалена отдельная кнопка остановки стресс-теста.
- Добавлено подробное логирование всего пятиминутного теста.

## v0007

- Убран автоматический выбор канала; добавлен явный выбор через **📣 Канал**.
- Добавлена LIVE-проверка канала, конкретных `saved_id`, типа подарка, slug, текущего номера, целей, цены и лимита.
- Исправлен строгий разбор логических настроек: строки `false`, `0`, `off` и `no` не включают LIVE.
- Платёжная форма обновляется при `FORM_EXPIRED` и `STARS_FORM_AMOUNT_MISMATCH`; ошибки обновления формы классифицируются безопасно.
- Добавлена обработка текущих ошибок платёжного и gift API, дополнительной верификации и повторной отправки формы.
- Перед финансовым запросом сохраняется постоянная защитная блокировка `saved_id → target`.
- Неизвестный результат не вызывает повторную оплату.
- При незавершённом платёжном результате запрещены сброс, смена канала, изменение подарков и целей.
- `FLOOD_WAIT` сохраняется в `/app/data/rate-limit.json` и блокирует новые MTProto-запросы до окончания cooldown.
- Остановка стресс-теста получила тайм-аут и принудительную отмену зависшего запроса.

## v0006

- Профиль: 1 минута на 300 мс, 1 минута на 120 мс, затем 3 минуты без искусственной паузы.
- Добавлены JSON/JSONL-отчёты и статистика задержки, частоты, CPU, RAM, ошибок и FloodWait.

## v0005

- Добавлены подтверждение фактического номера, обработка `PaymentVerificationNeeded` и безопасная остановка при неизвестном результате.
- Горячий цикл сокращён до одного запроса текущего номера на один тип подарка.

## v0004

- Добавлен адаптивный контроллер скорости и предварительная подготовка платёжной формы.

## v0003
