# Validation — Gift Hunter v0012

## Выполненные проверки

- `python -m compileall -q .`;
- `python -m unittest discover -s tests -p 'test_*.py'` в отдельном виртуальном окружении;
- 76 тестов бизнес-логики, платёжных блокировок, Telegram-схем, стресс-теста, глобального каталога и live-status;
- проверка фонового обновления карточки сканера без нажатия кнопок;
- проверка смены отображаемого номера `12841 → 12842` при цели `12850`;
- проверка фонового обновления карточки стресс-теста;
- проверка, что Bot API-обновление вынесено из измеряемого hot path стресс-теста;
- проверка восстановления: после двух ошибок редактирования создаётся новая карточка и новый `message_id` становится активным;
- проверка версии в `main.py`, `healthcheck.py`, документации и тестах;
- повторная распаковка итогового ZIP, компиляция и запуск тестов из распакованной копии.

## Граница проверки

Тесты не подключаются к пользовательской Telegram-сессии и не выполняют списание Stars. Пакетный индекс среды не предоставил закреплённые версии aiogram/Telethon, поэтому бизнес-логика и интерфейсные вызовы проверялись в изолированном окружении со строгими асинхронными заглушками Bot API и MTProto. Реальный Docker при деплое установит зависимости из `requirements.txt`.
