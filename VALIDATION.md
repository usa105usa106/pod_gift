# Validation — Gift Hunter v0018

## Выполненные проверки

- `python -m compileall -q .` — успешно;
- `python -m pytest -q` — 97 тестов пройдено;
- `python -m unittest discover -q` — 97 тестов пройдено;
- проверена компиляция `main.py`, `healthcheck.py` и тестов;
- проверено отсутствие автоматического `SendMessage` после неудачного редактирования;
- проверено, что `TelegramRetryAfter` останавливает повторные UI-запросы;
- проверено, что ручной выпуск новой карточки сохраняет известный срок блокировки;
- проверено, что `SendMessage RetryAfter` при ручном выпуске фиксируется одним запросом без цикла;
- проверено сохранение runtime-состояния, текущего номера, LIVE, подготовленной оплаты и обработанных целей при ручном выпуске;
- проверено обновление по событию смены номера независимо от минутного heartbeat;
- проверено отображение версии и остатка блокировки в `Ping`;
- проверено отображение времени карточки по МСК без изменения монотонных таймеров сканера;
- сохранены тесты exact-target guard, монотонного счётчика, платежной безопасности, FloodWait, стресс-теста, глобального каталога и безопасного сброса.

## Граница проверки

Тесты не подключаются к пользовательской Telegram-сессии и не выполняют реальное списание Stars. Реальный остаток Bot API `RetryAfter`, ответы разных Telegram DC и гонка с чужими запросами проверяются только после деплоя.
