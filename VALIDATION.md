# Validation — Gift Hunter v0017

## Выполненные проверки

- `python -m compileall -q .`;
- `pytest -q` — 94 теста;
- `python -m unittest discover -s tests -p 'test_*.py'` — 94 теста;
- проверка версии в `main.py`, `healthcheck.py`, документации и тестах;
- проверка ручного перевыпуска карточки при активном `RetryAfter` старого сообщения;
- проверка сохранения runtime-состояния, подготовленной оплаты и счётчика проверок при перевыпуске;
- повторная распаковка итогового ZIP, компиляция и запуск тестов из распакованной копии.

## Проверки v0017

- полное обновление карточки выполняется примерно раз в 3 секунды;
- кнопка `♻️ Обновить карточку` присутствует в основной клавиатуре;
- ручное нажатие отправляет новую карточку через `sendMessage` и переключает дальнейшие редактирования на новый `message_id`;
- старая карточка после перевыпуска больше не используется;
- локальный `RetryAfter` старой карточки очищается только после успешной отправки новой;
- перевыпуск не меняет состояние MTProto-сканера, проверки, цели, LIVE, подготовленные платёжные формы и список уже обработанных целей;
- повторный перевыпуск ограничен 10 секундами;
- сохранена точная проверка v0015: конкретный `цель − 1`, проверка целевого slug, монотонный номер и блокировка лишней оплаты;
- сохранены прежние тесты платежной безопасности, FloodWait, стресс-теста, глобального каталога и безопасного сброса.

## Граница проверки

Тесты не подключаются к пользовательской Telegram-сессии и не выполняют реальное списание Stars. Реальный ответ разных Telegram DC/кэшей и гонка с чужими запросами могут быть проверены только после деплоя.
