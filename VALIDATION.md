# Validation — Gift Hunter v0011

## Выполненные проверки

- `python -m compileall -q .`;
- `python -m unittest discover -s tests -p 'test_*.py'` в отдельном виртуальном окружении;
- 69 локальных тестов;
- проверка, что обработчик **🔢 Проверить номера** не вызывает `resolve_channel` и не читает подарки канала;
- проверка глобального каталога из нескольких `StarGift`, запросов `GetUniqueStarGiftRequest` и сортировки результата;
- проверка bounded concurrency: несколько коллекций действительно запрашиваются параллельно в пределах семафора;
- проверка, что ошибка одной коллекции не скрывает остальные;
- проверка, что **🎁 Подарки** не вызывает поиск текущих номеров;
- существующие тесты LIVE-платежа, неизвестного результата, `PaymentVerificationNeeded`, `FLOOD_WAIT`, защитной блокировки, стресс-теста и healthcheck;
- повторная распаковка итогового ZIP и запуск тестов из распакованной копии.

## Граница проверки

Тесты не подключаются к пользовательской Telegram-сессии и не выполняют списание Stars. Пакетный индекс среды не предоставил закреплённые версии aiogram/Telethon, поэтому бизнес-логика и формы RPC проверялись в изолированном окружении со строгими заглушками интерфейсов. Реальный Docker при деплое установит зависимости из `requirements.txt`.
