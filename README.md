# Gift Hunter v0011

Gift Hunter следит за текущим номером выбранной Telegram-коллекции и в LIVE-режиме отправляет улучшение, когда текущий номер равен `цель − 1`.

## Главное в v0011

Три функции снова разделены правильно:

- **🔢 Проверить номера** — глобальный каталог Telegram. Кнопка не использует выбранный канал и показывает все коллекции, доступные через `payments.getStarGifts`, с последним выданным номером.
- **🎁 Подарки** — только подарки выбранного канала. Здесь выбирается конкретный `saved_id` для улучшения; проверка последних номеров по каналу не выполняется.
- Сообщение `DurovsGlasses`, `Durov's Glasses` или ссылка `https://t.me/nft/DurovsGlasses-1` — точечная проверка одной коллекции.

Полный каталог проверяется ограниченно-параллельно. Значение по умолчанию — шесть одновременных read-only запросов. Его можно изменить переменной `CATALOG_CONCURRENCY`, но повышать без необходимости не рекомендуется.

## Установка в Coolify

1. Не удаляй Persistent Storage `/app/data`.
2. Загрузи все файлы архива в корень GitHub-репозитория с заменой.
3. Оставь переменные:

```env
BOT_TOKEN=токен_от_BotFather
SETUP_PIN=твой_секретный_PIN
MAX_UPGRADE_STARS=2000
CATALOG_CONCURRENCY=6
```

`MAX_UPGRADE_STARS` и `CATALOG_CONCURRENCY` необязательны: используются значения `2000` и `6`.

4. Нажми **Redeploy**.
5. Команда `/version` должна вернуть `Gift Hunter v0011`.

## Порядок работы

1. **📣 Канал** — выбрать канал.
2. **🎁 Подарки** — выбрать конкретный экземпляр.
3. **🎯 Задать номера** — указать цели.
4. **🧪 Стресс-тест: ВЫКЛ** — при необходимости выполнить пятиминутный тест.
5. **🛡 Оплата: ВЫКЛ** — переключить в LIVE после проверки настроек.
6. **▶️ Запустить** — начать адаптивное сканирование.

Полная проверка каталога блокируется во время активного сканера и стресс-теста, чтобы десятки read-only запросов не задерживали критический цикл.

## Стресс-тест

- 0–60 секунд: 300 мс;
- 60–120 секунд: 120 мс;
- 120–300 секунд: максимальная последовательная скорость.

Тест не создаёт платёжную форму и не улучшает подарок. Результаты сохраняются в `/app/data/stress-test-latest.json`, `/app/data/stress-tests.jsonl` и основном логе.

## Ограничение

Telegram не резервирует номер заранее. Даже при мгновенной отправке запроса другой участник может быть обработан сервером раньше.
