# Gift Hunter v0012

Gift Hunter следит за текущим номером выбранной Telegram-коллекции и в LIVE-режиме отправляет улучшение, когда текущий номер равен `цель − 1`.

## Главное в v0012

### Живая карточка сканера

После нажатия **▶️ Запустить** бот создаёт одну карточку и обновляет её примерно раз в секунду без дополнительных нажатий:

```text
Проверок: 184
Последний цикл: 31 мс
Фактический шаг: 47 мс
Rare Bird: текущий 12842 · цель 12850
Обновлено: 03:12:18
```

Когда Telegram выдаёт новые экземпляры, строка меняется автоматически: `12841 → 12842 → 12843`. Для этого не требуется нажимать Ping или Запустить повторно.

Если Telegram не позволяет редактировать старое сообщение, бот после двух неудачных попыток отправляет новую статусную карточку и продолжает обновление. Причина записывается в Log.

### Живая карточка стресс-теста

Стресс-тест обновляется каждые две секунды и показывает:

- прошедшее и оставшееся время;
- текущий этап и период;
- количество проверок и ошибок;
- текущую и максимальную скорость;
- среднюю задержку и P95;
- FloodWait;
- текущий номер выбранной коллекции.

Обновление интерфейса выполняется отдельной фоновой задачей и не учитывается в измеряемом MTProto-цикле.

### Разделение кнопок

- **🔢 Проверить номера** — глобальный каталог Telegram, независимо от выбранного канала.
- **🎁 Подарки** — только экземпляры выбранного канала для выбора `saved_id`.
- Сообщение `DurovsGlasses`, `Durov's Glasses` или ссылка `https://t.me/nft/DurovsGlasses-1` — проверка одной коллекции.

## Установка в Coolify

1. Не удаляй Persistent Storage `/app/data`.
2. Загрузи все файлы архива в корень GitHub-репозитория с заменой.
3. Оставь переменные:

```env
BOT_TOKEN=токен_от_BotFather
SETUP_PIN=твой_секретный_PIN
MAX_UPGRADE_STARS=2000
CATALOG_CONCURRENCY=6
```

Дополнительные необязательные настройки интерфейса:

```env
LIVE_STATUS_INTERVAL_SECONDS=1
STRESS_STATUS_INTERVAL_SECONDS=2
```

4. Нажми **Redeploy**.
5. Команда `/version` должна вернуть `Gift Hunter v0012`.

## Порядок работы

1. **📣 Канал** — выбрать канал.
2. **🎁 Подарки** — выбрать конкретный экземпляр.
3. **🎯 Задать номера** — указать цель, например `12850`.
4. **🧪 Стресс-тест: ВЫКЛ** — при необходимости выполнить пятиминутный тест.
5. **🛡 Оплата: ВЫКЛ** — переключить в LIVE после проверки настроек.
6. **▶️ Запустить** — начать адаптивное сканирование.

## Ограничение

Telegram не резервирует номер заранее. Даже при немедленной отправке запроса другой запрос может быть обработан сервером раньше.
