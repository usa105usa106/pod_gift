# Gift Hunter v0008

Gift Hunter следит за текущим номером выбранного Telegram collectible gift и в LIVE-режиме отправляет улучшение, когда выполняется условие:

```text
текущий номер = цель − 1
```

Например, при цели `3333` запрос улучшения отправляется сразу после ответа Telegram с текущим номером `3332`.

## Основные изменения v0008

- Стресс-тест управляется одним тумблером:
  - **🧪 Стресс-тест: ВЫКЛ** — нажать для запуска;
  - **🧪 Стресс-тест: ВКЛ** — нажать для досрочной остановки.
- Отдельной кнопки остановки стресс-теста нет.
- Через 5 минут тест автоматически завершается, тумблер возвращается в положение **ВЫКЛ**, бот отправляет итоговый отчёт и снова готов к запуску сканера.
- В системный Log записывается полный ход теста: начало, смена этапов, телеметрия каждую секунду, статистика каждой минуты, FloodWait, ошибки, остановка и итоговый JSON-отчёт.
- Сохраняются отдельные отчёты `/app/data/stress-test-latest.json` и `/app/data/stress-tests.jsonl`.
- Канал выбирается только вручную через **📣 Канал**.
- Каждый подарок хранится как отдельный экземпляр по `saved_id`.
- Перед LIVE повторно проверяются канал, подарок, slug, текущий номер, цели, цена и лимит Stars.
- Поддерживаются обычное платное и предоплаченное улучшение.
- `FLOOD_WAIT` сохраняется в `/app/data/rate-limit.json`; новые MTProto-запросы блокируются до окончания обязательной паузы.
- Неизвестный результат или дополнительная верификация создают защитную блокировку, поэтому повторная оплата не отправляется.

## Установка в Coolify

1. Не удаляй Persistent Storage `/app/data`.
2. Загрузи все файлы архива в корень GitHub-репозитория с заменой.
3. Задай переменные:

```env
BOT_TOKEN=токен_от_BotFather
SETUP_PIN=твой_секретный_PIN
```

`MAX_UPGRADE_STARS` необязателен. По умолчанию используется ограничение `2000` Stars на одну операцию.

4. Нажми **Redeploy**.
5. Команда `/version` должна вернуть:

```text
Gift Hunter v0008
```

## Настройка

1. **📣 Канал** — выбрать нужный канал.
2. **🎁 Подарки** — выбрать один или несколько отдельных экземпляров одного типа.
3. **🎯 Задать номера** — указать цели, например `3333, 4444`.
4. Нажать **🧪 Стресс-тест: ВЫКЛ** — тумблер станет **ВКЛ**, начнётся тест.
5. Через 5 минут получить итог и убедиться, что тумблер автоматически стал **ВЫКЛ**.
6. Включить LIVE через кнопку оплаты и подтверждение.
7. Нажать **▶️ Запустить**.

## Стресс-тест

Профиль теста:

- 0–60 секунд: период 300 мс;
- 60–120 секунд: период 120 мс;
- 120–300 секунд: максимальная последовательная скорость без искусственной паузы.

Тест только читает текущий номер. Он не создаёт платёжную форму, не отправляет оплату и не улучшает подарок.

В Log записываются:

- запуск и выбранный тип подарка;
- смена каждого этапа;
- одна строка телеметрии каждую секунду;
- отдельная статистика каждой из пяти минут;
- все FloodWait и сетевые ошибки;
- финальный отчёт и причина завершения.

Файлы отчёта:

```text
/app/data/gift-hunter-v0008.log
/app/data/stress-test-latest.json
/app/data/stress-tests.jsonl
/app/data/rate-limit.json
```

## Защита LIVE

Перед финансовым запросом бот сохраняет на диск `saved_id` и связанную цель. Подарок удаляется из выбора только после подтверждения фактического коллекционного номера. При неизвестном результате бот останавливается и не отправляет повторную оплату.

## Ограничения

Telegram не резервирует желаемый номер заранее. Если другой запрос будет обработан раньше, после обнаружения `3332` можно получить `3334` вместо `3333`. Код минимизирует задержку, но не может дать абсолютную гарантию номера.
