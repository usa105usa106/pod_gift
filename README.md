# Gift Hunter v0017

Gift Hunter следит за текущим номером выбранной Telegram-коллекции и в LIVE-режиме отправляет улучшение, когда текущий номер равен `цель − 1`.

## Карточка сканера

- вся информация обновляется примерно раз в 3 секунды;
- кнопка `♻️ Обновить карточку` отправляет новую карточку и переключает дальнейшие редактирования на её новый `message_id`;
- старая карточка после ручного перевыпуска больше не редактируется;
- ручной перевыпуск не останавливает MTProto-сканер, не сбрасывает проверки, подготовленную оплату, цель или LIVE;
- повторное нажатие ограничено паузой 10 секунд, чтобы не создавать дубли;
- если Telegram вернул `RetryAfter` для старой карточки, новая карточка всё равно отправляется отдельным `sendMessage`;
- MTProto-сканирование и LIVE-улучшение остаются полностью независимыми от интерфейса.

## Главное в v0017

- Возвращён полный live-статус раз в 3 секунды.
- Добавлена кнопка `♻️ Обновить карточку`.
- При нажатии бот сначала отправляет новое сообщение, затем атомарно сохраняет его как единственную активную карточку.
- Старое сообщение бросается без попытки остановить или перезапустить сканер.
- Новый `message_id` сбрасывает локальную паузу редактирования, связанную со старой карточкой.
- Сохранена защита v0015: точная проверка конкретных slug, монотонный номер и блокировка оплаты, если цель уже существует.
- Сохранена обработка `TelegramRetryAfter`: автоматические редактирования конкретной карточки выдерживают указанную Telegram паузу.

### Безопасный полный сброс

Кнопка **🗑 Сброс** теперь удаляет все рабочие настройки:

- выбранный канал;
- выбранные экземпляры подарков;
- целевые номера;
- LIVE/DRY-RUN;
- сохранённые slug-привязки;
- текущую статистику сканера и стресс-теста;
- незавершённый ввод в диалоге.

При этом всегда сохраняются:

- привязка владельца Telegram-бота;
- `TG_API_ID`, `TG_API_HASH` и номер телефона;
- MTProto SQLite-сессия (`*.session` и служебные файлы SQLite);
- `BOT_TOKEN` и другие переменные Coolify;
- логи, отчёты стресс-теста и обязательный FloodWait cooldown.

Сброс не отключает Telegram-сессию и не вызывает `disconnect`. Отключить её можно только вручную в настройках Telegram или удалением Persistent Storage `/app/data`.

Если есть платёж с неподтверждённым результатом, сброс по-прежнему блокируется до сверки — это защищает от повторного списания Stars.

### Живые карточки

После **▶️ Запустить** вся карточка обновляется примерно раз в 3 секунды. Если она перестала меняться, нажми **♻️ Обновить карточку**: бот отправит новое сообщение и продолжит редактировать уже его, не затрагивая сканирование и LIVE.

Стресс-тест длится только 5 минут и продолжает обновляться примерно раз в 3 секунды, показывая время, этап, проверки, скорость, задержки, FloodWait и текущий номер.

### Разделение кнопок

- **🔢 Проверить номера** — глобальный каталог Telegram, независимо от выбранного канала.
- **🎁 Подарки** — только экземпляры выбранного канала для выбора `saved_id`.
- Сообщение `DurovsGlasses`, `Durov's Glasses` или ссылка `https://t.me/nft/DurovsGlasses-1` — проверка одной коллекции.

## Установка в Coolify

1. Не удаляй Persistent Storage `/app/data`.
2. Загрузи все файлы архива в корень GitHub-репозитория с заменой.
3. Оставь переменные:

```env
BOT_TOKEN=токен_от_BotFather
SETUP_PIN=твой_секретный_PIN
MAX_UPGRADE_STARS=2000
CATALOG_CONCURRENCY=6
EXACT_PROBE_DISTANCE=100
EXACT_COUNTER_REFRESH_SECONDS=1.0
```

Дополнительные настройки интерфейса:

```env
LIVE_STATUS_INTERVAL_SECONDS=3
STATUS_MANUAL_REFRESH_COOLDOWN_SECONDS=10
STRESS_STATUS_INTERVAL_SECONDS=3
```

4. Нажми **Redeploy**.
5. Команда `/version` должна вернуть `Gift Hunter v0017`.

## Порядок работы

1. **📣 Канал** — выбрать канал.
2. **🎁 Подарки** — выбрать конкретный экземпляр.
3. **🎯 Задать номера** — указать цель, например `12850`.
4. **🧪 Стресс-тест: ВЫКЛ** — при необходимости выполнить пятиминутный тест.
5. **🛡 Оплата: ВЫКЛ** — переключить в LIVE после проверки настроек.
6. **▶️ Запустить** — начать адаптивное сканирование.

## Ограничение

Telegram не резервирует номер заранее. Точная проверка slug устраняет обнаруженную задержку агрегатного счётчика, но не отменяет гонку между последней проверкой и обработкой платежа Telegram.
